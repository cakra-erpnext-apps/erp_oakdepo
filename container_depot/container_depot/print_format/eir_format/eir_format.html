{#- EQUIPMENT INTERCHANGE RECEIPT — the survey sheet. Laid out after the OAK paper form (Rev. terbaru, compartment-based): one bordered header block carrying the tank's identity, then the checklist, then the tank's kelengkapan, then the two-party sign-off. What it takes from the rest of the depot's paperwork is the letterhead, the type scale and the palette. GROUPED BY AREA, the way the paper form groups its compartments: a full-width band names the area, the parts belonging to it follow underneath, and each area restarts its own numbering — which is what `printed_no` has always held (A01 and B01 are both "1"). A flat 1..138 run reads as one undifferentiated wall; banded, a surveyor finds "Bottom Discharge" by scanning bands instead of counting rows. ONE TABLE PER AREA, with the band living in its . A single table cannot repeat a mid-table row, so an area straddling the page break carried on unlabelled overleaf — which is exactly the context the banding exists to give. A repeats, so each area's band comes back at the top of the next page. The price is that column widths are no longer negotiated across the whole checklist: `table-layout: fixed` plus an explicit pins them, so the eight tables stack into one continuous grid. THREE COLUMNS, NOT TWO. The active taxonomy is 138 parts; at two columns that is 69 rows and three A4 pages of mostly empty cells. Three columns halves it. Within a band the fill is column-major, so the numbers still read downwards. The per-row remarks column went with it — on the paper form the codes live in the grid and the words live in the REMARKS box, so notes are collected underneath as "CATATAN TEMUAN" and only for the parts that actually carry one. Nothing is dropped; it is just not given a column that is blank 130 times out of 138. THE CODE KEY COMES FIRST. D and R print as bare numbers; the key that decodes them sits above the grid — as on the paper form — laid out as an aligned code/word grid rather than the run-on sentence it used to be, so a reader can find "17" by scanning a column. PORTRAIT, deliberately. The old template asked for landscape via `@page`, which wkhtmltopdf ignores — Frappe builds its page flags from declarations on `.print-format` — so this sheet has always printed portrait. Honouring the request turns out to cost paper rather than save it: A4 landscape is 87mm shorter, and with a checklist this long that is extra pages. Portrait it stays; `oak.styles(landscape=true)` is there for a format that genuinely needs the width.
